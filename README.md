# IDN E-Report

**IDN E-Report** is a web-based reporting interface designed to organize and display report information through a clean, modern, and user-friendly dashboard.

## 📌 About the Project

IDN E-Report is a web development project focused on creating a structured digital reporting interface. The project uses HTML, CSS, JavaScript, and Bootstrap to build a consistent user interface and improve the user experience.

## ✨ Features

- **Dashboard** — Displays the main reporting interface.
- **Reports Page** — Provides a dedicated page for viewing reports.
- **Single Report Page** — Displays individual report details.
- **Statistics Page** — Provides a dedicated interface for statistical information.
- **Settings Page** — Provides an interface for application settings.
- **Responsive Interface** — Designed to support different screen sizes.
- **Bootstrap Integration** — Uses Bootstrap resources to support interface development.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/muhammadzabranidn-hue/e-report.git
   ```

2. Navigate to the project directory:

   ```bash
   cd e-report
   ```

3. Open the project in Visual Studio Code.

4. Run `index.html` using the Live Server extension or open it directly in your browser.

## 📁 Main Directories

| Directory | Description |
